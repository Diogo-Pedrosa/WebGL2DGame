# WebGL2DGame

## O Jogo

Esse projeto é um tower defense em 2D com estética old west e foco em proteger um banco de assaltos. A ideia é simples: os bandidos aparecem pelo mapa, avançam pelo caminho até a base e o jogador precisa construir e melhorar torres para impedir que eles cheguem.

Além de posicionar torres, o jogo também permite clicar diretamente nos inimigos para causar dano, coletar moedas, comprar upgrades e lidar com hordas cada vez mais difíceis. O objetivo é manter o banco vivo e sobreviver o máximo possível sem deixar os bandidos roubarem tudo.

O jogo usa WebGL2 com canvas 2D, texturas e um visual bem simples, mas funcional. No começo dá para jogar tranquilo, e conforme o tempo passa a dificuldade aumenta e a pressão fica maior.

## Opcionais

Os itens abaixo são os que eu implementei no projeto:

- Novas torres: posicionamento de torres no mapa
- Progressão da torre: evolução de Deputy para Sheriff
- Moedas: sistema de economia para construir e melhorar
- Hordas: dificuldade crescente com ondas de inimigos
- Inimigos diferentes: variação na base dos bandidos
- Caminhos dos inimigos: os bandidos seguem um caminho pré-definido
- Power-ups: drops de upgrades durante a partida
- Música de fundo: trilha sonora em loop
- Tela cheia: botão para alternar entre modo janela e tela cheia
- Tela de game over: reinício do jogo após derrota
- Clique para dano: o jogador pode dar dedadas nos inimigos

## Observação

Esse jogo foi feito como parte do TP1 de Computação Gráfica e a ideia era criar um jogo parecido com bloons td utilizando WebGL. O resultado final ficou mais voltado pra um estilo old west, com bandidos, torres, upgrades e uma base para defender.
